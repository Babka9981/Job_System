# Как читать эту папку

`dashboard.html` показывает этапы и прогресс. `state.js` хранит состояние сборки.
Папка с датой содержит исходное ТЗ, требования, спецификацию и таски.
Суффикс `--wip` означает незавершённую работу.
Для продолжения: «продолжи автопилот».
