## Критерии приёмки

- [ ] Reader session отдельна от bot; локальная auth и приватное хранение, отказ => reconnect.
- [ ] Все 41 адреса проверяются при доступной session; добавление/отключение по ссылке сохраняет registry.
- [ ] Checkpoint/повтор/несколько вакансий/edited/deleted события покрыты; точная post ссылка, private access hint.
- [ ] Неоднозначное разбиение поста не изобретает вакансии, показывает необходимость проверки.
- [ ] Только обычные фильтры по умолчанию; LLM permission требует документированного основания.
- [ ] Forward/manual paste не обходят запрет; независимый разрешённый JD может дополнять карточку.
- [ ] FloodWait/нет доступа/история недоступна не останавливают остальные источники.
