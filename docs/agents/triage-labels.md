# Triage Labels

| Role              | Tracker label       | Meaning                             |
| ----------------- | ------------------- | ----------------------------------- |
| `needs-triage`    | `needs-triage`      | Задача ожидает первичной оценки |
| `needs-info`      | `needs-info`        | Требуется дополнительная информация |
| `ready-for-agent` | `ready-for-agent`   | Задача готова для выполнения агентом |
| `ready-for-human` | `ready-for-human`   | Требуется выполнение человеком |
| `wontfix`         | `wontfix`           | Задача не будет выполнена |

Эти значения используются и в локальной строке `Status:`, и в GitHub labels.
