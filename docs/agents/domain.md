# Domain Docs

Перед исследованием проекта необходимо читать:

- `CONTEXT.md` в корне проекта;
- относящиеся к области работы ADR из `docs/adr/`.

Если файлов ещё нет, продолжать без предупреждения. Они создаются по мере формирования терминологии и архитектурных решений.

## Layout

Проект использует single-context структуру:

```
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

## Vocabulary

В коде, задачах, тестах и документации использовать термины из `CONTEXT.md`. Не заменять определённые термины случайными синонимами.

## ADR conflicts

Если предлагаемое решение противоречит существующему ADR, явно указать конфликт и причину возможного пересмотра решения.
