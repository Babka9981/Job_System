# Profile extraction получает output budget 8000 токенов

## Контекст

Production-вызов `gpt-5-mini` с 4000 output tokens завершился incomplete/invalid structured JSON, тогда как тот же budget-enforced сценарий с 8000 создал сохраняемый draft. Альтернативами были оставить 4000 и сокращать результат либо безусловно поднять лимит без связи с ценой и суточным бюджетом.

## Решение

Использовать для profile extraction default `JOB_PROFILE_MAX_OUTPUT_TOKENS=8000`. Значение допускает environment override, передаётся как `max_output_tokens` и входит в консервативную максимальную стоимость, резервируемую до transport-вызова.

## Почему

Лимит 4000 доказанно недостаточен для полной structured-схемы реального CV, а обрезанный JSON не даёт пригодного частичного результата. Настраиваемый лимит 8000 обеспечивает завершение ответа, не превращая его в безусловное право расхода: точная цена модели и суточный cap по-прежнему могут остановить вызов до отправки данных.

## Последствия

Предварительный резерв для extraction становится больше и может чаще давать pending при малом дневном бюджете. Override должен сохраняться при setup/deploy и учитываться тем же расчётом стоимости; увеличение лимита не гарантирует расход всех 8000 токенов, а settlement фиксирует фактическую стоимость ответа.
