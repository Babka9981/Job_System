# Vuexy-inspired Operations UI

Переносимая дизайн-спецификация административного интерфейса. Папку можно
целиком скопировать в другой репозиторий и передать разработчику или ИИ-агенту
с указанием:

> Реализуй интерфейс по `design-system/README.md` и связанным документам. Сохрани
> бизнес-логику проекта и выполни критерии из
> `design-system/ACCEPTANCE_CHECKLIST.md`.

## Состав папки

- [`DESIGN_SPEC.md`](./DESIGN_SPEC.md) — полное описание визуального языка,
  компоновки, компонентов, адаптивности и доступности.
- [`tokens.css`](./tokens.css) — готовые CSS-переменные светлой и тёмной тем.
- [`AGENT_BRIEF.md`](./AGENT_BRIEF.md) — короткое задание для ИИ-агента или
  команды разработки.
- [`ACCEPTANCE_CHECKLIST.md`](./ACCEPTANCE_CHECKLIST.md) — проверяемые критерии
  готовности.
- [`REFERENCES.md`](./REFERENCES.md) — внешние референсы и документация.

## Как подключить

1. Скопировать папку `design-system` в корень нового проекта.
2. Подключить `design-system/tokens.css` к глобальным стилям либо перенести
   переменные в существующую систему тем.
3. Передать разработчику ссылку на этот файл.
4. Реализовать базовые примитивы из `DESIGN_SPEC.md` до разработки отдельных
   страниц.
5. Проверить результат по `ACCEPTANCE_CHECKLIST.md` в обеих темах и на всех
   контрольных ширинах.

## Важное ограничение

Дизайн вдохновлён компоновкой Vuexy, но является самостоятельной реализацией.
Не копировать исходный код, иллюстрации, логотипы, платные компоненты или другие
материалы Vuexy без соответствующей лицензии.
