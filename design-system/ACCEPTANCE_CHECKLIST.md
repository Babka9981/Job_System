# Чек-лист приёмки

## Визуальная система

- [ ] Используются только семантические токены из `tokens.css`.
- [ ] Интерфейс вдохновлён Vuexy, но не копирует его материалы.
- [ ] Подключён Inter с системными fallback-шрифтами.
- [ ] Карточки, формы, таблицы и кнопки имеют единое оформление.
- [ ] Нет неоформленных системных inputs, selects, textareas и buttons.

## Темы

- [ ] Светлая тема полностью покрывает все страницы и состояния.
- [ ] Тёмная тема полностью покрывает все страницы и состояния.
- [ ] При первом посещении используется системная тема.
- [ ] Выбор пользователя сохраняется после перезагрузки.
- [ ] Выбор синхронизируется между вкладками.
- [ ] При загрузке нет заметной вспышки неправильной темы.

## Компоновка

- [ ] На desktop есть sidebar 16rem и topbar 4.25rem.
- [ ] Sidebar можно скрыть и вернуть.
- [ ] До 992 px sidebar превращается в drawer.
- [ ] Drawer закрывается по Escape, backdrop и выбору раздела.
- [ ] Фокус корректно возвращается на кнопку меню.
- [ ] Страница не имеет горизонтального overflow.
- [ ] Таблицы прокручиваются только внутри своего контейнера.

## Контрольные ширины

- [ ] 1920×1080.
- [ ] 1280×800.
- [ ] 992×900.
- [ ] 768×1024.
- [ ] 390×844.

## Компоненты и состояния

- [ ] Реализованы общие Card, PageHeading, FieldGrid и ActionGroup.
- [ ] Реализованы StatusBadge и FeedbackBanner всех пяти тонов.
- [ ] Реализованы EmptyState, LoadingState и ErrorState.
- [ ] Ошибка предлагает повторную попытку, когда она возможна.
- [ ] Disabled и saving-состояния не допускают повторную отправку.
- [ ] Длинные данные не разрушают сетку.
- [ ] Карточки не растягивают соседей без необходимости.

## Доступность

- [ ] Всё доступно с клавиатуры.
- [ ] Каждый control имеет доступное имя.
- [ ] `focus-visible` заметен в обеих темах.
- [ ] Активная навигация использует `aria-current="page"`.
- [ ] Меню использует `aria-expanded` и `aria-controls`.
- [ ] Ошибки объявляются через `role="alert"`.
- [ ] Фоновые статусы используют `aria-live` или `role="status"`.
- [ ] Есть skip-link к основному содержимому.
- [ ] Контраст обычного текста не ниже 4.5:1.
- [ ] Увеличение текста до 200% не ломает функции.
- [ ] Axe не находит серьёзных WCAG 2.2 AA нарушений.

## Финальная проверка

- [ ] Все бизнес-сценарии работают после редизайна.
- [ ] Проверены loading, ready, empty, error и permission denied.
- [ ] Проверены обе темы на каждой контрольной ширине.
- [ ] Нет ошибок или предупреждений в консоли браузера.
- [ ] В отчёте перечислены все отклонения от спецификации.
